Practical Notes

یادداشت‌های عملی — آستانه‌گذاری، مورفولوژی و Contour

نکاتی که در آموزش معمولی پیدا نمی‌شوند: به‌دردبخورها، تله‌ها و تجربه‌های میدانی همین ماژول.

★
مهم‌ترین یادگرفتنی

اگر فقط یک چیز از این ماژول یادت بماند: هیچ روش آستانه‌گذاری/Contour ثابتی روی همه‌ی تصاویر جواب نمی‌دهد. تمرین شمارش سکه‌ی همین ماژول دقیقاً همین را نشان داد — بازه‌ی مساحت که برای یک عکس درست بود، برای عکس دیگر (فاصله‌ی دوربین متفاوت) غلط از آب درآمد. همیشه پارامترها را روی چند نمونه‌ی متفاوت تست کن، نه فقط یک عکس.

✕
تله‌ی زمان‌بر ۱ — پس‌زمینه‌ی اشتباه برای findContours

رایج‌ترین باگ این ماژول: بعد از threshold، شیء موردنظر سیاه شده ولی پس‌زمینه سفید است (بستگی به نوع THRESH_BINARY یا _INV و رنگ اصلی تصویر دارد). نتیجه: findContours به‌جای شیء، مرز کل تصویر یا نویز پس‌زمینه را پیدا می‌کند. همیشه بعد از باینری‌کردن یک plt.imshow بزن و چک کن شیء واقعاً سفید روی سیاه است — اگر نبود، cv2.bitwise_not.

✕
تله‌ی زمان‌بر ۲ — فراموش‌کردن فیلتر نویز قبل از moments

بعد از findContours، همیشه چند کانتور خیلی کوچک (چند پیکسلی، از نویز لبه‌ی آستانه‌گذاری) هم پیدا می‌شوند. اگر مستقیم روی همه‌شان cv2.moments بزنی، برای کانتورهای تک‌پیکسلی m00 ممکن است صفر شود و کد با ZeroDivisionError کرش کند. فیلتر cv2.contourArea(c) > N را همیشه قبل از هر محاسبه‌ی دیگر بگذار.

✓
تیپ به‌دردبخور — connectedComponentsWithStats را به findContours ترجیح بده وقتی فقط شمارش/bbox می‌خواهی

اگر فقط لازم است بشماری چند جزء وجود دارد یا bounding box هرکدام چیست (نه شکل دقیق مرز)، connectedComponentsWithStats سریع‌تر و ساده‌تر از ترکیب findContours + boundingRect است — مساحت و bbox را از قبل در آرایه‌ی stats آماده می‌دهد.

✓
تیپ به‌دردبخور — شکل کرنل مورفولوژی را متناسب با هدف انتخاب کن

یک کرنل مربعی (np.ones) برای حذف نویز عمومی خوب است، ولی وقتی هدف خاص است (مثلاً فقط خطوط افقی)، یک کرنل کشیده در همان جهت (getStructuringElement(MORPH_RECT, (width, 1))) دقیق‌تر و قابل‌کنترل‌تر عمل می‌کند — این تکنیک را در تمرین حذف خطوط دیدیم.

# قطعه‌ی آماده‌ی کپی‌پیست — پیش‌پردازش امن قبل از هر تحلیل Contour import cv2 gray = cv2.cvtColor(img, cv2.COLOR_BGR2GRAY) blur = cv2.medianBlur(gray, 5) binary = cv2.adaptiveThreshold( blur, 255, cv2.ADAPTIVE_THRESH_GAUSSIAN_C, cv2.THRESH_BINARY, 11, 2 ) binary = cv2.bitwise_not(binary) # همیشه چک کن شیء واقعاً سفیده contours, _ = cv2.findContours(binary, cv2.RETR_EXTERNAL, cv2.CHAIN_APPROX_SIMPLE) contours = [c for c in contours if cv2.contourArea(c) > 100] # همیشه قبل از moments فیلتر کن
