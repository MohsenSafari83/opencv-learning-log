Cheat Sheet

برگه‌ی تقلب — آستانه‌گذاری، مورفولوژی و Contour

خلاصه‌ی فشرده‌ی توابع، سینتکس‌ها و الگوهای پرکاربرد ماژول ۳؛ برای رجوع سریع، نه یادگیری از صفر.

آستانه‌گذاری

تابعمشخصات و خروجیمثال سریع
cv2.threshold(img,thresh,max,type)آستانه‌ی ثابت؛ خروجی (ret, dst)threshold(img,127,255,BINARY)
... + cv2.THRESH_OTSUآستانه‌ی خودکار سراسری؛ آرگومان thresh نادیده گرفته می‌شودthreshold(img,0,255,BINARY+OTSU)
cv2.adaptiveThreshold(...)آستانه‌ی محلی؛ برای نور نامتوازنadaptiveThreshold(img,255,GAUSSIAN_C,BINARY,11,2)

مورفولوژی

تابعمشخصات و خروجیمثال سریع
cv2.erode(img,kernel)لاغرکردن نواحی سفیدerode(img,k,iterations=1)
cv2.dilate(img,kernel)چاق‌کردن نواحی سفیدdilate(img,k,iterations=1)
MORPH_OPENerode سپس dilate — حذف نویز سفید کوچکmorphologyEx(img,MORPH_OPEN,k)
MORPH_CLOSEdilate سپس erode — پرکردن سوراخ‌های کوچکmorphologyEx(img,MORPH_CLOSE,k)
MORPH_HITMISSیافتن یک الگوی دقیق (کرنل با 1/0/-1)morphologyEx(img,MORPH_HITMISS,k)
cv2.getStructuringElement(shape,size)کرنل با شکل خاص (RECT/ELLIPSE/CROSS)getStructuringElement(MORPH_RECT,(w,1))

اجزای متصل و Contour

تابعمشخصات و خروجیمثال سریع
cv2.connectedComponents(img)برچسب‌زنی نواحی سفید متصل → (num, labels)connectedComponents(bin_img)
connectedComponentsWithStats(img)مثل بالا + مساحت/bbox/مرکز هر جزء آماده→ num,labels,stats,centroids
cv2.findContours(img,mode,method)مرز نواحی سفید؛ روی پس‌زمینه‌ی سیاهfindContours(bin,RETR_TREE,APPROX_SIMPLE)
cv2.drawContours(img,cnts,idx,color,t)idx=-1 یعنی همه‌ی کانتورهاdrawContours(img,cnts,-1,c,2)
cv2.contourArea(cnt)مساحت کانتور — برای فیلتر نویز و سورتsorted(cnts,key=cv2.contourArea)
cv2.moments(cnt)گشتاورها؛ مرکز جرم = m10/m00, m01/m00M['m10']/M['m00']
cv2.boundingRect(cnt)کوچک‌ترین مستطیل راست‌گوشه → (x,y,w,h)x,y,w,h = boundingRect(cnt)
cv2.minEnclosingCircle(cnt)کوچک‌ترین دایره‌ی محاط‌کننده(cx,cy), r = minEnclosingCircle(cnt)
cv2.convexHull(cnt)پوش محدب (صاف‌کردن مرز نامنظم)hull = convexHull(cnt)
cv2.approxPolyDP(cnt,eps,closed)تقریب چندضلعی؛ eps از arcLength می‌آیدapproxPolyDP(cnt,0.01*peri,True)

اشتباهات رایج
  • Contour روی پس‌زمینه‌ی اشتباه: findContours دنبال شیء سفید روی پس‌زمینه‌ی سیاه می‌گردد. اگر بعد از threshold متن/شیء سیاه شده، حتماً cv2.bitwise_not بزن.
  • تقسیم بر صفر در moments: اگر کانتور خیلی کوچک باشد (m00=0)، محاسبه‌ی مرکز جرم کرش می‌کند — همیشه اول با contourArea > threshold فیلتر کن.
  • connectivity اشتباه: دو شیء که فقط از گوشه به هم چسبیده‌اند، با connectivity=8 یکی و با connectivity=4 دو تا حساب می‌شوند.
  • Otsu روی نور نامتوازن: Otsu یک آستانه‌ی سراسری می‌دهد؛ روی تصویر با سایه/نور ناهموار، Adaptive Thresholding را امتحان کن.

gray = cv2.cvtColor(img, cv2.COLOR_BGR2GRAY) blur = cv2.medianBlur(gray, 5) # حذف نویز قبل از آستانه‌گذاری binary = cv2.adaptiveThreshold(blur, 255, cv2.ADAPTIVE_THRESH_GAUSSIAN_C, cv2.THRESH_BINARY, 11, 2) binary = cv2.bitwise_not(binary) # شیء باید سفید باشد contours, _ = cv2.findContours(binary, cv2.RETR_EXTERNAL, cv2.CHAIN_APPROX_SIMPLE) contours = [c for c in contours if cv2.contourArea(c) > 100] # فیلتر نویز
