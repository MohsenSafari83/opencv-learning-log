خوشه‌بندی چیست؟ (39)

خوشه‌بندی (Clustering) یک روش یادگیری بدون‌نظارت است که داده‌ها را بر اساس شباهت، در چند گروه (خوشه) دسته‌بندی می‌کند، بدون اینکه از قبل برچسبی برای داده‌ها وجود داشته باشد. برخی کاربردهای رایج آن:

  • فشرده‌سازی داده (Compression)
  • پیش‌پردازش برای سیستم‌های توصیه‌گر (Recommender systems)
  • گروه‌بندی اخبار یا نتایج جستجوی مرتبط (مثل Google News)
  • گروه‌بندی سهام‌های مرتبط برای مدیریت پورتفولیو
  • ساخت پروفایل مشتری برای تحلیل بازار
  • ساخت یک code book از نمونه‌های نمونه برای استخراج ویژگی بدون‌نظارت

یک دیتاست دو‌بعدی مصنوعی می‌سازیم و با K-Means آن را به سه خوشه تقسیم می‌کنیم:

cv2.calcHist(images, channels, mask, bins, ranges) پنج آرگومان می‌گیرد:

  • images — تصویر ورودی، به‌صورت لیست (مثلاً [image])
  • channels — اندیس کانال مورد نظر به‌صورت لیست ([0] برای تصویر سطح‌خاکستری؛ [0]/[1]/[2] برای آبی/سبز/قرمز در تصویر رنگی)

  • bins — تعداد سطل‌های هیستوگرام برای هر کانال
  • ranges — بازه‌ی مقادیر ممکن پیکسل، که برای تصاویر ۸ بیتی [0, 256] است
import matplotlib.pyplot as plt import numpy as np import cv2 image = cv2.imread('images/input.jpg',0) histogram = cv2.calcHist([image], [0], None, [256], [0, 256]) plt.figure(figsize=[5,3]) plt.plot(histogram)

لبه‌یابی با Laplacian (50)

Sobel از مشتق مرتبه‌ی اول استفاده می‌کند: در محل لبه، مقدار مشتق اول یک قله (تغییر ناگهانی) نشان می‌دهد. اگر یک بار دیگر مشتق بگیریم (مشتق مرتبه‌ی دوم)، در محل دقیق لبه مقدار صفر می‌شود (Zero-crossing) و همین ویژگی هم برای تشخیص لبه قابل استفاده است — با این تفاوت که صفر فقط منحصر به لبه‌ها نیست.

Laplace(f) = ∂²f/∂x² + ∂²f/∂y²

لبه‌یابی با Canny (51)

cv2.Canny یک الگوریتم چندمرحله‌ای است (بلور گاوسی، محاسبه‌ی گرادیان، Non-Maximum Suppression و آستانه‌گذاری دوگانه با Hysteresis) که معمولاً تمیزترین و نازک‌ترین لبه‌ها را می‌دهد و رایج‌ترین روش لبه‌یابی در OpenCV است.

import cv2 import numpy as np import matplotlib.pyplot as plt plt.figure(figsize=[12,7]) src = cv2.imread("images/little_girl.jpg") edges = cv2.Canny(src,100,200) plt.subplot(121),plt.imshow(src[...,::-1]);plt.title('Original Image') plt.subplot(122),plt.imshow(edges,cmap = 'gray');plt.title('Edge Image')

cv2.Canny دو آستانه می‌گیرد (پایین و بالا): لبه‌های قوی‌تر از آستانه‌ی بالا قطعاً لبه هستند، لبه‌های ضعیف‌تر از آستانه‌ی پایین قطعاً حذف می‌شوند، و لبه‌های بین این دو فقط اگر به یک لبه‌ی قوی متصل باشند نگه داشته می‌شوند (Hysteresis). با یک Trackbar می‌توان تاثیر آستانه‌ی پایین را به‌صورت زنده دید:

  • فضای رنگی HSV چون رنگ (Hue) را از روشنایی (Value) جدا می‌کند، برای فیلتر کردن رنگ با cv2.inRange از BGR مناسب‌تر است؛ رنگ قرمز چون دو سر طیف Hue قرار دارد به دو ماسک جداگانه نیاز دارد.

  • حذف پرده‌ی سبز و افکت Color Pop هر دو روی همان ایده‌ی ماسک رنگی و ترکیب بیتی (bitwise_and/bitwise_not/add) ساخته می‌شوند.
  • رنگ‌های غالب یک تصویر را می‌توان با خوشه‌بندی K-Means (دقیق‌تر، کندتر) یا هیستوگرام کانال Hue (سریع‌تر، تک‌بعدی) پیدا کرد.
  • هیستوگرام توزیع مقادیر پیکسل را نشان می‌دهد؛ cv2.calcHist ابزار اصلی محاسبه‌ی آن است و باید قبل از مقایسه‌ی دو هیستوگرام آن‌ها را نرمال کرد چون به سایز تصویر حساس است.
  • یکنواخt‌سازی هیستوگرام (equalizeHist) کنتراست سراسری تصویر را بهبود می‌دهد؛ CLAHE با تقسیم تصویر به بلوک‌های کوچک و محدود کردن تقویت نویز، نسخه‌ی تطبیقی و معمولاً بهتر آن است.
  • فیلترهای blur (box، Gaussian، median، bilateral) نویز را کم می‌کنند؛ هرکدام مصالحه‌ی متفاوتی بین حذف نویز و حفظ لبه دارند. کرنل‌های sharpening با تفریق یک نسخه‌ی بلورشده از تصویر اصلی، جزئیات را تقویت می‌کنند.
  • لبه‌ها با مشتق‌گیری از تصویر پیدا می‌شوند: کرنل ساده و Sobel از مشتق مرتبه‌ی اول، Laplacian از مشتق مرتبه‌ی دوم (zero-crossing)، و Canny با ترکیب بلور، گرادیان، Non-Maximum Suppression و آستانه‌گذاری دوگانه، معمولاً تمیزترین نتیجه را می‌دهد.
  • برای خروجی گرادیان با مقادیر منفی (لبه‌های تیره‌به‌روشن)، باید ddepth را cv2.CV_64F یا مشابه آن گذاشت، وگرنه با ddepth پیش‌فرض (uint8) نیمی از اطلاعات لبه با Clip شدن از بین می‌رود.
