برگه‌ی تقلب — highgui (ماوس، Trackbar، ویدیو)

خلاصه‌ی فشرده‌ی توابع، سینتکس‌ها و الگوهای پرکاربرد ماژول ۲؛ برای رجوع سریع، نه یادگیری از صفر.

رویدادهای ماوس و Trackbar

تابع / الگومشخصات و خروجیمثال سریع
cv2.setMouseCallback(win, fn)اتصال تابع callback به پنجرهsetMouseCallback('w', draw)
def fn(event,x,y,flags,param)امضای ثابت تابع callback ماوسdef draw(e,x,y,f,p): ...
cv2.EVENT_LBUTTONDOWN/UP/MOUSEMOVEپرکاربردترین رویدادهاif event==EVENT_LBUTTONDOWN
cv2.createTrackbar(name,win,val,max,fn)ساخت اسلایدر؛ fn هربار مقدار تغییر کرد اجرا می‌شودcreateTrackbar('R','w',0,255,cb)
cv2.getTrackbarPos(name, win)خواندن مقدار فعلی Trackbar (برای الگوی nothing-callback)r = getTrackbarPos('R','w')

منابع ویدیویی (Capture)

تابع / منبعمشخصاتمثال سریع
cv2.VideoCapture(0)وب‌کم پیش‌فرض سیستمcap = VideoCapture(0)
cv2.VideoCapture(path)فایل ویدیویی محلیVideoCapture('a.mp4')
cv2.VideoCapture(rtsp_url)استریم دوربین مداربسته/IPVideoCapture('rtsp://...')
ret, frame = cap.read()الگوی یکسان برای همه‌ی منابع بالاret, frame = cap.read()
cap.get(cv2.CAP_PROP_*)خواندن خاصیت (FPS، عرض، ارتفاع، ...)cap.get(CAP_PROP_FPS)
cap.release()آزادسازی دوربین/فایل — فراموش‌نشدنیcap.release()

ذخیره‌ی ویدیو

تابعمشخصاتمثال سریع
cv2.VideoWriter_fourcc(*'XVID')کد کدک؛ XVID/MJPG/X264 رایج‌ترین‌هاfourcc(*'XVID')
cv2.VideoWriter(path,fourcc,fps,size,isColor)ساخت writer؛ isColor باید با نوع فریم هم‌خوانی داشته باشدVideoWriter('o.avi',fc,20,(w,h))
out.write(frame)نوشتن یک فریمout.write(frame)
out.release()بستن و finalize فایل خروجیout.release()

!
اشتباهات رایج
  • فراموش‌کردن cap.release(): دوربین قفل می‌ماند و برنامه‌ی بعدی نمی‌تواند بازش کند — باید سیستم را ری‌استارت کنی.
  • ret چک نشده روی فایل: بعد از تمام‌شدن ویدیو، frame می‌شود None؛ بدون if not ret: break کرش می‌کنی.
  • isColor اشتباه در VideoWriter: اگر فریم گری‌اسکیل بدهی ولی isColor=True (پیش‌فرض) بماند، خروجی خراب یا خطا می‌شود.
  • مختصات (x,y) در callback ماوس در برابر [y,x] در slicing: همان تله‌ی ماژول ۱، اینجا هم صادق است.

الگوی امن باز و بسته‌کردن منبع ویدیویی

مستقل از این‌که منبع وب‌کم، فایل، یا RTSP باشد، همیشه این اسکلت را رعایت کن:

cap = cv2.VideoCapture(source) while True: ret, frame = cap.read() if not ret: break # ... پردازش فریم ... cv2.imshow('win', frame) if cv2.waitKey(1) & 0xFF == 27: break cap.release() cv2.destroyAllWindows()
